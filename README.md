# bitbank Bot

## 概要

暗号資産市場で自動取引を行うトレーディングボット。定義した戦略に基づいて注文を自動実行し、継続的な取引機会を活用する。

暗号資産市場は 24 時間・価格変動も速いため、裁量取引だけでは機会を取りこぼしやすい。本ボットで戦略の自動実行とデータ蓄積により改善サイクルを回す。

## ボット取引の考え方

役割分担は次のとおり。

| 役割 | 内容 |
| ---- | ---- |
| 人間 | 戦略の設計・分析・改善 |
| ボット | 戦略の自動実行 |

人間が戦略を決め、ボットがそれを高速・継続的に実行する。

この仕組みで実現できること:

- 24 時間自動取引
- 感情に左右されない取引
- 高頻度の取引実行
- 一貫したルールの実行

## ボットの目的

1. **定義された戦略を自動実行する** — ルールに基づき注文を出す。
2. **取引データを蓄積し戦略改善につなげる** — 結果を分析し、戦略を改善する。

ボットは取引の実行だけでなく、その結果の分析を通じて戦略改善の材料を提供する。
